# PLATFORM-DOCS: where the shared docs live

Master copies of the cross-repo docs live only in the `platform` repo. This repo keeps no copies (the old
`docs/master/`, `docs/project/` and `WORKLOG-PROJECT.md` snapshots were removed because they drifted).

Online: https://github.com/gokulsaraswat/platform/tree/main/docs
Local (workspace checkout): `../platform/docs/`

| Doc | What it holds |
|---|---|
| [RULES.md](https://github.com/gokulsaraswat/platform/blob/main/docs/RULES.md) | Global agent rules (this repo's `RULES.md` is a synced copy) |
| [CONTEXT.md](https://github.com/gokulsaraswat/platform/blob/main/docs/CONTEXT.md) | Vision, repo map, contracts, work modes |
| [CONTRACTS.md](https://github.com/gokulsaraswat/platform/blob/main/docs/CONTRACTS.md) | Shared interfaces, packages, tables, config |
| [BACKLOG.md](https://github.com/gokulsaraswat/platform/blob/main/docs/BACKLOG.md) | Master backlog index (P0/P1 and cross-repo items) |
| [WORKLOG.md](https://github.com/gokulsaraswat/platform/blob/main/docs/WORKLOG.md) | Master status of all repos |
| [DESIGN-BRIEF.md](https://github.com/gokulsaraswat/platform/blob/main/docs/DESIGN-BRIEF.md) | Design system v2 brief (flavors, tokens, components) |
| [REPO-KIT.md](https://github.com/gokulsaraswat/platform/blob/main/docs/REPO-KIT.md) | Files every repo must carry |
| [PROMPTS.md](https://github.com/gokulsaraswat/platform/blob/main/docs/PROMPTS.md) | Session prompts |

Private notes (`PRIVATE-*.md`, `Not Repository/`) live only at the workspace root and are never committed.
